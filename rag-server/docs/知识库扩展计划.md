## 3. 迁移说明与项目影响

### 已执行

### 对项目的影响（结论：**无代码级破坏，lists 不必重新入库**）

| 影响面 | 说明 |
|--------|------|
| **已入库的 Chroma/BM25** | **完全不受影响**。检索走向量/BM25 索引，不读磁盘上的源文件路径 |
| **lists/ 换目录** | 只是源文件备份位置变了；**8 份清单若早已 ingest 进 `travel_plan`，无需再 ingest** |
| **若误对 lists/ 再 ingest** | 新路径会被当成另一份文档，可能产生**重复 chunk**；只有当你改了清单正文、想更新索引时才需要重新 ingest（并应先删旧文档） |
| **Golden Test Set** | `expected_sources` 按文档**标题**匹配，与路径无关；lists 迁移**无需改 JSON** |
| **本轮真正要入库的** | 仅 **新增** 的 `food/`、`prep/`（及之后的 `cities/`） |
| **代码硬编码** | 无模块依赖 `data/documents/` 路径 |

### 已更新文档引用

- `agents-master/README.md`：ingest 示例路径改为 `data/sources/travel_plan/`
- `docs/管理面板指南.md`：清空数据说明改为 `data/sources/`

## 6. 文档内容约定

### 6.1 美食与饮食注意（已编写）

路径：`food/美食与饮食注意（全面版）.md`

- 国内非遗美食与地方特色（分区域表格式）
- 海外饮食速查
- 特殊人群：儿童、老人、孕妇、清真、素食、糖尿病、痛风等
- 常见过敏原与应急沟通话术

### 6.2 通用行前实操清单（已编写）

路径：`prep/通用行前实操清单.md`

- 出发前时间线、证件订单、行李物品
- 资金支付、通讯网络、健康安全
- 国内/国际专项、出发当日检查表、返程事项

### 6.3 城市深度攻略（你自备）

建议单篇含：经典动线、停留时长、闭馆/预约、住宿区、市内交通、避坑。  
实时票价/开放时间写「出行前核实」。

### 6.4 agent_notes（暂缓项目文档）

| 状态 | 说明 |
|------|------|
| **暂缓** | 项目文档（DEV_SPEC 精选、架构设计、排障记录等）尚未整理好，**本轮不入库** |
| **先做** | 你可向 `agent_notes/` 放入其他学习文档，入库后供知识库问答使用 |
| **后续** | 项目文档整理完成后，作为 C1 任务补充入库 |
